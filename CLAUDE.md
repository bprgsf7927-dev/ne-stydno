# «Не стыдно» — правила для Claude

Общие правила всех семейных проектов (документация, спеки, коммиты, общение) — в приватном репозитории `bprgsf7927-dev/all_projects`, файл `CLAUDE.md`. Если доступа к нему нет — попросить Алену. Этот файл дополняет общие правила.

## Документация

- **ADR** — в приватном репозитории `bprgsf7927-dev/all_projects`, папка `ne-stydno/adr/` (as-is). В этом публичном репозитории ADR не держим: архитектура, защита и данные не публикуются.
- **Спеки** — `docs/tasks/YYYY-MM-DD_тема.md`, иммутабельные; статус только в шапке.
- **Диаграммы C4** — там же, `all_projects/ne-stydno/architecture/`.
- **Стиль** — `docs/STYLE.md`: обязателен для любого нового элемента интерфейса.
- **Работа с Даней** — `docs/MENTORING.md`: Даня — продакт, Claude — ментор.
- **Бэклог идей** — `docs/BACKLOG.md`; открытые вопросы и дорожная карта — проект «Данилка» в claude.ai (`claude/ne-stydno-status.md`).

## Кто пишет в чат

Даня представляется в начале чата. Если не представился — уточнить, кто пишет: с Даней и с Аленой разные роли (ADR, страница «Роли»).

## Перед коммитом

- `tools/bump.sh` — обновить версию файлов, чтобы телефоны не держали старый кэш.
- Контент правится только в исходниках (`content.xlsx`, `tools/content_*.py`), JSON пересобирается скриптами — см. `README.md`.
- Код функции Yandex Cloud (`server/yandex-function/index.js`) Алена загружает в консоль сама — после изменения дать ей ZIP и шаги.

## Публичность

Репозиторий публичный. Секреты, токены, личные данные людей, описание архитектуры и защиты — никогда не коммитить сюда.
