# Не стыдно

Веб-тренажер по школьной истории. Проект Дани: он отвечает за стиль, персонажей и шутки, Алена — за техничку и контент, ассистент — за код.

Сейчас: История, 6 класс — один курс на учебный год, две книги в школьном порядке: Всеобщая история (Мединский, Чубарьян, 2025), главы I–VI, и История России IX — начала XVI в. (Мединский, Торкунов, 2025), главы 1–4. Книга и номер главы — колонки book/num на листе «Главы». Новые главы пишутся в `tools/content_*.py` (`content_sv_1_4.py` — главы I–IV, `content_rossiya.py` — История России) и вливаются в xlsx: `python3 tools/add_content.py content_sv_1_4`, потом `python3 tools/xlsx2json.py`.

## Гео-тренажер (география, 6 класс)

Учебник «География. 5–6 классы», «Полярная звезда» (Алексеев, Николина и др.). Работает на движке истории: «даты» — числа (длины рек, высоты водопадов; `century` — группа для «по порядку»), «личности» — объекты (реки, водопады). Флаг `GEO` в `js/app.js` меняет формулировки. Контент: `tools/content_geo6.py` → `python3 tools/geo2json.py` → `content/geografia-6/`. Сейчас: §34–35 «Реки — артерии Земли». У объектов есть материк, куда впадает, страны — из них задания «где это»: рисованная карта материков (ткни, где течет), выбор материка, куда впадает, по каким странам, пары с материками, «найди лишнее», «разложи по материкам»; в Качалке раздел «Карта». Карта — `WORLD` в `js/app.js`.

## Русича-тренажер (русский язык, 6 класс)

Второй предмет, переключается кнопкой «предмет ▾» (или `?s=russkiy`). Прогресс у предметов раздельный. Учебник Баранова, Ладыженской и др., часть 1.

- Вместо дат — понятия. Карточка: «по учебнику» (близко к тексту), сразу за ним «простыми словами», пример, ключевые пункты, ловушка.
- Механики на понимание: найди ошибку у Ника, почему так, собери определение (один блок лишний), пары внутри темы, правда/ложь, «Объясни Опти» — пишешь своими словами, потом сравниваешь с карточкой и сам отмечаешь, какие ключевые пункты назвал.
- Источник правды — модули `tools/content_rus6_*.py` (не xlsx): `gl1` — глава 1, `gl2` — глава 2, `rech` — главы 3–5, `lex` и `lex2` — глава 6 (одна глава может лежать в двух модулях, скрипт их сливает). После правки: `python3 tools/rus2json.py`. Новый модуль добавить в список MODULES в этом скрипте.
- id параграфов в JSON с префиксом `ya` (ya1, ya37), чтобы не пересекаться с Историей России (r1…).
- Код: `RUS`, `buildRusTasks()`, `buildBossRus()` и механики `tNik`, `tWhy`, `tBuild`, `tRPairs`, `tExplain` в `js/app.js`.

## Качалка

Вкладка внизу: вся глава за одну тренировку — даты, термины или личности. Каждый пункт минимум дважды (в маленьких главах до 4 раз, чтобы вышло 7–10 минут), механики каждый раз новые, ошибки возвращаются в конце. Код: `buildGym()` в `js/app.js`.

## Запустить локально

Сайт статический, сборки нет. Но вопросы грузятся через `fetch`, поэтому открывать нужно через сервер, а не двойным кликом по файлу.

Терминал 2 (из папки проекта):

```bash
python3 -m http.server 3000
```

Открыть http://localhost:3000. На телефоне в той же Wi-Fi сети — `http://<ip-мака>:3000`.

## Как добавлять и править контент

1. Открыть `content/srednie-veka-6/content.xlsx`, править нужный лист (легенда на первом листе). Столбец `id` не трогать.
2. В терминале из папки проекта: `python3 tools/xlsx2json.py`
3. Обновить страницу. Закоммитить и xlsx, и json.

Листы: Даты (с ассоциацией `assoc` и мини-фактом `more`), Термины, Персоналии, Причины, Тексты (пропуски `{0} {1} {2}`), Правда-ложь, Уроки (какие даты в каком уроке), Главы.

## Как устроено обучение

- **Экран = параграф.** Сверху плашка с параграфом (тап — список всех по главам). Ниже змейка: тренировки (звезды) → сундук после второй → тренировки → контрольная (лист). Число тренировок зависит от объема параграфа (3–8), длинные параграфы разрезаны на части (§21-22 ·1 и ·2).
- **Тренировка = 8 заданий**, шесть механик вперемешку: пары, выбор, порядок, вставить слово, напечатать год, правда/ложь. Пройдена от 70%, корона за 100%, любую можно переигрывать.
- **Знакомство через подводки**: в первых трех тренировках параграфа часть заданий — «первые встречи», где ответ почти очевиден из контекста; через одно задание спрашивают по-настоящему. Первая тренировка открывает вторую при любом результате. Книжка сбоку от карты — весь параграф карточками, на любой момент.
- **Сундук** — повторение прошлого параграфа, за 70% дает сердце (до трех). **Босс главы** — отдельный экран (юрта/замок) с тремя уровнями, на третьем жизни = сердца.
- **Микс дня** — 5 заданий из ошибок и давно не повторявшегося. Обратная связь всегда: «Ты прав / Ты не прав / Почти», при ошибке — ассоциация, мини-факт за кнопкой «хочу все знать».
- Прогресс, XP, стрик, сердца — в браузере телефона (до этапа 2).
