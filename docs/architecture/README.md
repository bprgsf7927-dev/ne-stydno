# Диаграммы C4

Mermaid (C4Context, C4Container). Показывают только то, что реально работает — не план. Обновлять в том же коммите, где меняется архитектура: новый контейнер, новый внешний сервис, новое хранилище.

- `context.mmd` — система и внешние сервисы
- `container.mmd` — из чего состоит система

Посмотреть: GitHub показывает Mermaid прямо в файле, если обернуть в блок ```mermaid; либо https://mermaid.live — вставить текст файла.
