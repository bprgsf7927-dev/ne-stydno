# Аккаунты — вход, прогресс в облаке, кабинет

Дата: 2026-11-08. Статус: в работе. Обновлено 08.11 вечером: вход только через Telegram, бэкенд — Yandex Cloud вместо Supabase (решение Алены по предложению архитектора).

## Секция 0. Принятые решения (Даня, 08.11)

- **Вход: только Telegram** (было: + почта; почту убрали 08.11 — у школьника скорее есть Telegram, чем почта, которую он читает; без Telegram можно играть без аккаунта). Одна кнопка «Войти через Telegram», без пароля и без ввода телефона: сайт открывает бота по ссылке `t.me/<бот>?start=<код>`, ученик жмет «Старт», бот подтверждает вход, сайт это замечает и входит.
- **Вход мягкий, как в Duolingo.** Играть можно сразу, без аккаунта: прогресс живет в телефоне (localStorage, как сейчас). Аккаунт предлагаем, когда уже есть что терять: после первой короны / первого сундука / стрика 3 дня — «У тебя 3 короны и огонь 3 дня. Не потеряй — сохрани». Отказ помнить, не доставать чаще раза в неделю. Жесткого экрана «войди, иначе не пущу» нет нигде.
- **Храним минимум.** Прогресс: шаги карты (`steps`), раскладки (`layouts`), XP, стрик, сердца, боссы, качалка, ошибки. Личное: только ник и аватар. Никаких фамилий, школ, классов, возраста, телефонов. От Telegram берем только id и имя для ника по умолчанию (ник можно сменить), почту храним только для входа.
- **Бэкенд — Yandex Cloud** (было: Supabase). Причина: Supabase работает через Cloudflare, а Cloudflare в России с 2025 года замедляют — прогресс сохранялся бы через раз. Yandex Cloud: одна функция Cloud Functions (`server/yandex-function/index.js`) + бакет Object Storage (по JSON на ученика). Данные в России, для нашего объема бесплатно.
- **Синхронизация:** при входе — слияние телефона и облака (берем большее: XP, стрик, лучший результат по шагу; шаги объединяем). Дальше облако — главное, телефон — кэш, чтобы работало в метро; пишем в облако после каждой тренировки, если нет сети — догоняем при следующем открытии.
- **Экспа и аватар — фундамент для магазина за экспу** (идея Дани, бэклог): XP уже есть, потраченная экспа и купленные вещи позже добавятся в тот же профиль. Аватар сразу делаем так, чтобы на него можно было навесить вещи (слои).

## Секция 1. Кто что делает

**Даня + Claude (фронт):**
- Вкладка «Кабинет» в нижней панели: аватар, ник, XP, стрик, короны, кнопка «Сохранить прогресс» (если не вошел) / «Выйти» (если вошел).
- Экран выбора аватара: собрать из Опти/Ника/Душки как база + свои варианты (человечек-палочка с разными прическами и лицами в стиле дудла). Слои — чтобы потом магазин одевал.
- Мягкое предложение сохранить прогресс: когда и как показываем, реплики персонажей (Ник переживает за прогресс — это его тема).
- Экран входа: одна кнопка «Войти через Telegram» и состояние «ждем, когда нажмешь Старт в боте» (с кнопкой «Открыть бота еще раз»).
- Слияние прогресса на фронте (`mergeState()`): правила выше.

**Алена + Claude (бэк):**
- Бот в Telegram (@BotFather) — Алена.
- Yandex Cloud: бакет, сервисный аккаунт, функция с кодом из `server/yandex-function/index.js` — Алена по инструкции Claude.
- API функции: `POST ?r=start` (код входа), `POST ?r=tg` (вебхук бота), `GET ?r=check&code=` (ждем «Старт»), `GET/PUT ?r=progress` (прогресс по токену). Токен сессии подписан секретом функции, живет полгода.
- Секреты (токен бота и т.п.) — только в переменных окружения функции, в репозиторий не попадают. В `js/config.js` — только адрес функции и имя бота.
