# 2. Нефункциональные требования

[← ADR](README.md)

Общие требования для всех семейных проектов (PWA, приложение-оболочка, Yandex Cloud, данные детей, репозитории) — в [`all_projects/docs/nft.md`](https://github.com/bprgsf7927-dev/all_projects/blob/main/docs/nft.md). Здесь — только то, что специфично для «Не стыдно».

## Работа без аккаунта и без сети

Заниматься можно без регистрации: прогресс хранится в телефоне (`localStorage`). Аккаунт нужен, только чтобы не потерять прогресс и заниматься с разных устройств. Вход мягкий — предлагается, когда есть что терять. (решение 08.11.2026)

**Риск — Safari стирает данные сайта,** если сайт неделю не открывали и он не добавлен на экран «Домой». Защита — облачное сохранение через аккаунт.

## Персональные данные — нет

«Не стыдно» не собирает персональные данные: логин видит только сам ученик, ник собирается из генератора двух слов (свой текст ввести нельзя), аватар — набор нарисованных частей. Имя, возраст, класс, школа, телефон, почта, фото не хранятся. (решение 10.11.2026 — `docs/tasks/2026-11-10_akkaunty-login.md`)

## Безопасность аккаунтов

**Пароль и код восстановления** — только хэши scrypt с солью. **Защита от подбора:** 5 неверных попыток — пауза 15 минут, 15 попыток — час. **Сессия** — подписанный токен на полгода; при смене пароля или восстановлении все старые сессии перестают работать. **Удаление аккаунта** — пользователь сам, с подтверждением паролем, стирает все. (изм. 10.11.2026 — `docs/tasks/2026-11-10_akkaunty-login.md`)

**Логи функции** — только текст ошибки, без тел запросов, паролей и IP. Срок хранения логов — 3 дня (настройка в консоли Yandex Cloud — задача Алены, не подтверждена).

## Друзья — правила безопасности

*Не реализовано, этап 2б.* Принятые правила: поиска по нику нет, добавление только по коду друга или QR (живет 48 часов), дружба по взаимному согласию, никакого свободного текста — только стикеры и вызовы, лидерборд только среди друзей, кнопка «пожаловаться». (решение 10.11.2026 — `docs/tasks/2026-11-10_akkaunty-login.md`)

## Открытость

Репозиторий публичный: Даня делится ссылкой с друзьями. При первых платных функциях или чужих взрослых пользователях — разделить на публичный движок и приватный контент. (решение 26.10.2026)

## Страница «Какие данные мы храним»

`privacy.html` — простыми словами для детей и родителей. Сейчас без ссылки с сайта: включается вместе с экранами входа.

## Нагрузка

Сайт статический — нагрузку держит GitHub Pages. Функция вызывается редко: раз в день от устройства (счетчик) и при входе и синхронизации. Квоты бесплатного уровня Yandex Cloud достаточно.
