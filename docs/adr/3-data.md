# 3. Модели данных

[← ADR](README.md)

## Данные в телефоне (localStorage)

**Прогресс предмета** — свой ключ на предмет: `istoria-trainer-v3`, `russkiy-trainer-v1`, `geografia-trainer-v1`. Поля: `xp` (экспа), `streak` и `lastDay` (огонь — дни подряд), `wrong` (ошибки для повторения), `seen` (что ученик уже видел), `steps` (пройденные шаги карты параграфа и проценты), `layouts` (раскладка заданий по шагам), `hearts` (сердца на босса), `bosses` (боссы глав), `gym` (качалка), `current` (текущий параграф), `moreClicks` (нажатия «хочу все знать»). Старые ключи `istoria-trainer-v1/v2` переносятся в v3 при первом входе.

**Профиль** — `ne-stydno-profile`, общий для всех предметов: ник и аватар. Сейчас ник в кабинете — свободный текст; по спеке аккаунтов v2 его заменит генератор.

**Служебное:** `ne-stydno-subject` — выбранный предмет; `ne-stydno-device` — случайный id устройства для счетчика (16 hex-символов, не связан с человеком); `ne-stydno-runs` — тренировки с последней отправки; `ne-stydno-ping` — день последней отправки.

## Контент курса (JSON в репозитории)

`content/<курс>/`: `lessons.json` (параграфы), `topics.json` (главы), `facts.json` (даты; в географии — числа), `terms.json` (термины и понятия), `persons.json` (личности; в географии — объекты), `causes.json`, `cloze.json` (вставить слово), `truefalse.json`; у русского еще `nik.json`, `why.json`, `build.json`, `rpairs.json`. Курсы: `srednie-veka-6` (история), `russkiy-6`, `geografia-6`. Источники и сборка — [1. Технический стек](1-stack.md).

## Данные в облаке (Object Storage, бакет `ne-stydno-progress`)

По одному JSON-объекту на ключ. (изм. 10.11.2026 — `docs/tasks/2026-11-10_akkaunty-login.md`)

| Ключ | Что хранит |
|---|---|
| `login/<логин>.json` | `uid`; соль и хэш пароля; соль и хэш кода восстановления; `fails` — неверные попытки; `lock` — пауза до |
| `acc/<uid>.json` | `login`; `nick` — пара id слов из генератора `{a, n}`; `avatar` — id частей и цвет; `created`; `tv` — версия сессий |
| `prog/<uid>.json` | `state` — прогресс; `updated` — время сохранения |
| `devices/<id>.json` | Счетчик: первый и последний день, предметы. Без связи с аккаунтом |
| `stats.json` | Сводка счетчика: устройства, тренировки, аккаунты, по дням (60 дней), по предметам |

**Аккаунт — внутренний номер `uid`** (24 hex-символа, случайный). Способы входа привязаны к нему: сейчас один — логин и пароль. Вход через Telegram, VK ID, Яндекс ID добавится к тому же `uid` без переделки (бэклог).

**Логин** — 4–20 символов, латиница, цифры, точка, подчеркивание; без учета регистра; уникальный. Уникальность: проверка + условная запись + перечитывание.

**Ник не хранится текстом** — только id слов. Списки слов — в коде сайта; через API нельзя записать произвольный текст.

## Что не хранится

Имя, фамилия, возраст, класс, школа, телефон, почта, фото, голос, геолокация, IP-адреса.
