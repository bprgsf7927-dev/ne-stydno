# 1. Технический стек

[← ADR](README.md)

## Клиент

**Статический сайт без сборки.** Одна страница `index.html`, стили `css/style.css`, логика `js/app.js` (карта, тренировки, качалка, прогресс), персонажи `js/characters.js`, аватар ученика `js/avatar.js`, карта мира `js/worldmap.js` (грузится только в географии). Фреймворков и сборщика нет — Даня правит файлы напрямую.

**Предметы — один движок.** Предмет выбирается кнопкой «предмет ▾» или параметром `?s=`: история (`istoria`), русский (`russkiy`), география (`geografia`). География работает на движке истории: «даты» — числа, «личности» — объекты (реки, водопады). У русского свои механики на понимание. Биология заведена выключенной.

**PWA-основа.** Есть `manifest.webmanifest`: сайт добавляется на экран «Домой» и открывается во весь экран. Service worker и веб-пуши пока не сделаны — см. общие НФТ, раздел 1.

**Обновление без кэша.** `tools/bump.sh` перед коммитом проставляет версию `window.APP_V` и `?v=` у файлов. Сайт сверяет свою версию с опубликованной и перезагружается на новую, когда ученик не в тренировке.

**Шрифты:** рукописный Caveat — во всех заголовках, системный — в тексте (`docs/STYLE.md`).

## Контент

**Контент собирается из исходников в JSON.** Сайт читает `content/<курс>/*.json`; руками JSON не правится.

- История: источник правды — `content/srednie-veka-6/content.xlsx` и модули `tools/content_*.py` → `tools/add_content.py` → `tools/xlsx2json.py`.
- Русский: модули `tools/content_rus6_*.py` → `tools/rus2json.py` → `content/russkiy-6/`.
- География: `tools/content_geo6.py` → `tools/geo2json.py` → `content/geografia-6/`; карта мира — Natural Earth 1:110 млн, сборка `tools/build_worldmap.mjs`.

## Бэкенд

**Одна функция Yandex Cloud Functions** (Node.js 22), код — `server/yandex-function/index.js`. Маршруты: аккаунты (регистрация, вход, восстановление, смена пароля, профиль, удаление), прогресс, анонимный счетчик (`ping`, `stats`). Хранилище — бакет Object Storage `ne-stydno-progress`, доступ по IAM-токену сервисного аккаунта функции. Зависимостей npm нет: только встроенные `crypto` и `fetch`. (изм. 10.11.2026 — `docs/tasks/2026-11-10_akkaunty-login.md`)

**Загрузка кода функции** — вручную, Алена в консоли Yandex Cloud: ZIP-архив с `index.js`. Переменные окружения: `BUCKET`, `SESSION_SECRET`, `SITE_URL`.

**Состояние на 16.11.2026:** код функции с аккаунтами v2 лежит в репозитории; загружен ли он в Yandex Cloud — не подтверждено. Экранов входа на сайте нет — аккаунты пользователям недоступны.

## Хостинг

**Сайт — GitHub Pages** из ветки `main` репозитория. Бэкенд — Yandex Cloud (данные в России).

## Инструменты

Python 3 — сборка контента; Node.js — карта мира и функция; Playwright — проверка экранов при разработке.
