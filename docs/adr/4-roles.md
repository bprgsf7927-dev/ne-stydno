# 4. Роли

[← ADR](README.md)

Единственное место, где описываются роли и права. Остальные страницы ADR роли не перечисляют.

## Роли в системе

| Роль | Кто | Что может |
|---|---|---|
| Гость | Любой, кто открыл сайт | Заниматься всеми предметами, прогресс — в телефоне; кабинет с ником и аватаром |
| Ученик с аккаунтом | Зарегистрировался логином и паролем | То же + прогресс в облаке, вход с любого устройства, смена ника, аватара и пароля, удаление аккаунта. *Экраны входа еще не сделаны — роль доступна только через API* |
| Друг | Ученик, принявший заявку | Видит ник, аватар, экспу за неделю, огонь, короны; стикеры и вызовы. *Не реализовано, этап 2б* |

Администратора в интерфейсе нет. Данные в облаке видят только те, у кого доступ к консоли Yandex Cloud (Алена). Жалобы на друзей (этап 2б) разбирает Алена.

## Роли в команде

| Кто | Зона |
|---|---|
| Даня | Продакт: фронтенд, стиль, игровые фичи, вовлечение, ачивки, эвенты, персонажи. Решает, что и зачем делаем |
| Алена | Образовательная методика; архитектура вместе с Claude; бэкенд, который Даня пока не потянет; консоль Yandex Cloud и настройки GitHub Pages; родительские фичи — после подтверждения Дани. В инициативы Дани не вмешивается |
| Claude | Архитектура вместе с Аленой; контент учебников по методике Алены; ведет репозиторий; с Даней — ментор (`docs/MENTORING.md`) |
