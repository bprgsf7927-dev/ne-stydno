# 5. Разделы UI

[← ADR](README.md)

Краткая карта экранов as-is. Подробные функциональные стандарты (механики, правила прохождения, тексты) дополняются по итогам функциональной проработки. Стиль всех экранов — строго по `docs/STYLE.md`.

| Экран | Что делает |
|---|---|
| Приветствие (`screen-welcome`) | Стартовая во весь экран, без панелей. Показывается один раз на весь тренажер и по тапу на название |
| Карта параграфа (`screen-home`) | Один параграф = один экран, змейка шагов как в Duolingo: знакомство → тесты → сундук → тесты → контрольная параграфа; переключатель параграфов сверху; после последнего параграфа главы — босс |
| Карточки (`screen-cards`) | Знакомство и подсмотр материала без штрафа |
| Тренировка (`screen-task`) | Уроки по 8 заданий, механики вперемешку; тренировка до 100% с короной; у русского — механики на понимание и «Объясни Опти»; у географии — карта мира |
| Босс главы (`screen-boss`) | Контрольная главы в 3 уровня, сердца из сундуков |
| Качалка (`screen-gym`) | Вся глава за один подход: даты / термины / личности (в географии — и карта), каждый пункт минимум дважды, 7–10 минут, шкала «7 из 30» |
| Кабинет (`screen-cabinet`) | Ник и аватар ученика (человечек-палочка из слоев). Вход и регистрация — по спеке `docs/tasks/2026-11-10_akkaunty-login.md`, *экраны не сделаны* |
| Результат (`screen-result`) | Итог тренировки: экспа, ошибки |
| «Скоро» (`screen-soon`) | Заглушка для разделов, которых еще нет |

**Панели.** Верхняя (предмет, звезда, огонь, пицца) и нижняя (меню) закреплены на всех экранах, кроме приветствия; содержимое прокручивается между ними.

**Персонажи** Опти, Ник и Душка (`js/characters.js`) — на всех экранах, по `docs/STYLE.md`.

**Отдельные страницы:** `stats.html` — публичный счетчик учеников; `privacy.html` — «Какие данные мы храним» (пока без ссылки с сайта).
