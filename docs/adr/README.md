# «Не стыдно» — Architecture Decision Record

ADR описывает систему **как она работает сейчас** (as-is). Изменения вносятся через спеки в `docs/tasks/` и отмечаются пометкой «(изм. ДД.ММ.ГГГГ — спека)». Правила процесса — [`all_projects/CLAUDE.md`](https://github.com/bprgsf7927-dev/all_projects/blob/main/CLAUDE.md). Открытые вопросы и план — в дорожной карте (проект «Данилка» в claude.ai, `claude/ne-stydno-status.md`), не здесь.

## Паспорт сервиса

| | |
|---|---|
| Назначение | Тренажер по школьным предметам для 6 класса: история, русский язык, география. «Уроки, которые не стыдно учить» — коротко, смешно, с обратной связью как в Duolingo |
| Продакт | Даня — фронтенд, стиль, игровые фичи, персонажи (Опти, Ник, Душка) |
| Архитектура | Алена и Claude |
| Методика и контент | Методика — Алена; контент учебников — Claude по методике Алены |
| Разработка | Claude (ведет репозиторий), с Даней — в режиме ментора (`docs/MENTORING.md`) |
| Стек | Статический сайт (HTML, CSS, JS без сборки) + функция Yandex Cloud — [1. Технический стек](1-stack.md) |
| Сайт | https://bprgsf7927-dev.github.io/ne-stydno/ |
| Счетчик учеников | https://bprgsf7927-dev.github.io/ne-stydno/stats.html |
| Репозиторий | GitHub [bprgsf7927-dev/ne-stydno](https://github.com/bprgsf7927-dev/ne-stydno) (публичный) |
| Среды | Одна среда — продуктив на GitHub Pages; тестовой среды нет, локально — `python3 -m http.server 3000` |
| Пользователи | Даня и его друзья; сайт открыт всем по ссылке |
| Критичность | Некритичный. SLA нет |
| Монетизация | Нет. Донат «накормить автора пиццей» через CloudTips (`docs/DONATE.md`) |
| Поддержка | Вопросы — Алене |
