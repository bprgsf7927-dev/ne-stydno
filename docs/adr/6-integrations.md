# 6. Интеграции

[← ADR](README.md)

| Сервис | Зачем | Как |
|---|---|---|
| GitHub Pages | Хостинг сайта | Публикация из ветки `main`; включено Аленой в настройках репозитория |
| Yandex Cloud Functions | Бэкенд: аккаунты, прогресс, счетчик | Сайт обращается по HTTPS к `https://functions.yandexcloud.net/d4epkag2qmmj8fa10ptq?r=...`; CORS — только адрес сайта (кроме `stats`) |
| Yandex Object Storage | Данные аккаунтов, прогресс, счетчик | Бакет `ne-stydno-progress`; функция ходит по IAM-токену своего сервисного аккаунта |
| CloudTips | Донат «накормить автора пиццей» | Ссылка из шапки сайта; аккаунт на Алену (`docs/DONATE.md`) |

**Telegram не используется.** Вход через Telegram убран 10.11.2026: российские провайдеры режут доступ к Telegram Bot API из Yandex Cloud. Код входа через Telegram — в истории git, вход через Telegram, VK ID, Яндекс ID — в бэклоге. (изм. 10.11.2026 — `docs/tasks/2026-11-10_akkaunty-login.md`)

**Аналитики и рекламы нет.** Счетчик учеников — свой, анонимный ([3. Модели данных](3-data.md)).
